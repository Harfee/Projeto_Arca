
Abrir Termimal VSCODE

git init - Criar Repositorio

git remote add origin https://github.com/Harfee/Projeto_Arca.git - Serve para conectar o repositório local do computador para GitHub !!

git status - Verificar em qual branch está ou simplesmente verificar o status

git checkout -b main - Criar uma branch e trocar uma branch nova chamada main

git add "." - Para adicionar os arquivos no repositório atual e o ".." e para adicionar repositório pai

git commit -m "Commit inicial" - Apenas "salva" as alterações no seu computador (no repositório local) (Ele ainda não envia nada para a internet/GitHub)

git push origin main - Envia os arquivos salvos para o GitHub





pull request - Pega de uma branch e mescla em outra branch (melhor fazer pelo GitHub)
